# Conflict as a Bug — v0.1

## Goal

Turn a conflict into a shared object that two people can describe and inspect together.

## Initial interaction

1. One person creates a case and describes the conflict.
2. The application creates a shareable link.
3. The second person opens the link and adds their perspective.
4. Both perspectives become part of the same shared case.

## Scope

Version 0.1 focuses on one conflict and two participants.
